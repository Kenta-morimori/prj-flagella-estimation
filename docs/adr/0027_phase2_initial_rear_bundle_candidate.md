# ADR 0027: 後方束に近い初期配置の候補

## Context

Issue #263は、#255四方式比較のCを最初の対照とし、束に近い配置から維持能力を調べる。Cの初期3本は後方平行だが互いに離れており、1秒の観測では定常束を確認できていない。

## Decision

既定profileを変えず、`flagella.initial_bundle_mode: compact_rear`をopt-inで追加する。Cの付着位置・内部らせん形状・hook長を保ち、各べん毛鎖を後方へ剛体移動する。hook方向は外向き径方向から後方へ60～90°を10°刻みで調べ、菌体表面内向きのhookを避ける。菌体の軸方向範囲内では初期ビーズを菌体外接円柱の外側に置く。非付着bodyビーズ・他べん毛ビーズとの非重複とCより小さい横方向幅を必須にする。成立候補は初期hook力、横方向幅、角度の順に選ぶ。任意の1本の位相摂動は根元ビーズを固定した剛体回転で与える。

幾何preflightはhook角度を記録するが、この候補に90°を要求しない。hook長・非重複は必須とし、初期hook力を隠さない。Cのframe・motor・torsion・相互作用などの物理設定は短期screenの3条件で揃える。

## Consequences

- 配置が見つからなければ実行前に停止し、制約を報告する。
- Cで採用した物理設定の妥当性は未確定である。短期QCが成立しても束維持・定常回転・推進の成立は別途判断する。
- 初期hookの長軸直交はcompact候補で失われる。動的なhook対菌体軸角は従来通り診断専用とする。
