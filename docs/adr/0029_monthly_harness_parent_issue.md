# ADR 0029: 月次ハーネス棚卸しの親 Issue

- Status: accepted
- Date: 2026-10-19
- Source: Issue #266 / #268

## 背景

従来は継続 Issue #252 に各回の評価と採択実装を集め、月次親 Issue を作らなかった。2026-10 月の棚卸しでは、その回の判断・進捗と採択実装を一組として追えるようにすることを採択した。

## 判断

ユーザーが月次棚卸しを依頼し、判断が確定した回だけ、#252 の sub-issue として月次親 Issue を1件作る。各回の評価・根拠・採択／保留／却下・振り返りは月次親を正本とし、#252 は索引と短い要約を保って OPEN のまま継続する。採択した実装は当該月次親の sub-issue とし、実際の完了依存がない限り blocking 関係を作らない。月次親は採択事項がなければ記録確定後、採択事項があれば子 Issue の完了と振り返り後に閉じる。

既定モデル変更時の事前比較は通常手順として残す。#268 の `gpt-6.1-sol` / `medium` 移行はユーザーが比較省略を採択した今回限りの例外とし、改善効果は次回の月次親で実測できる値だけを確認する。定期自動実行・自動 Issue 作成は行わない。

具体的な運用手順の正本は `docs/codex/monthly_harness_review.md` とする。
