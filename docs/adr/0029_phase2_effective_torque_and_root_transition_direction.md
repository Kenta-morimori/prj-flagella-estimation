# ADR 0029：有効vector torqueと軸上の根元移行部を修正主案にする

2026-11-11追記：[接続research統合](../phase2/phase2_263_connector_research_synthesis.md)に、D+Jを基準とする相対位相の仕事によるMと近位内部応答Kの比較案を記録した。静的prototypeでの成立性と動的成功を区別し、このADRのProposedを維持する。新motorのproduction実装・科学的採択・実行予約は行っていない。

## 問題

現行segment力対は指定軸方向Tを満たしても、個別の横投影距離が小さいと大きい力/横トルクを作る。全体系の反作用QCはこの駆動の妥当性を保証しない。既存の加算minimum_norm補正では合力/合トルクに出ない力が残る。

また、最初のbeadをらせん外周の点として固定長hookでつなぐ構成は、軸回転と接続長維持に相対運動を要求する。Mの作用点移動・Gの剛体並進だけではこの構造を検証していなかった。

## 推奨する設計

1. **D**：各べん毛のゼロ合力・全vector T eを、全鎖上の最小ノルム力としてゼロから生成する。I=sum(|r|²1-r rT)、F=(I^-1 T e)×r。one-ringへ逆vectorを返す。最初の比較で駆動軸は現行SVDと同じ。剛体fit角速度と力の仕事の一致を仕様に含める。
2. **J**：現在の付着点/hook自然長/bead数/結合長/遠位形状を保持し、根元を軸上から細く立ち上げる。近位の自然角は設計geometryから事前に固定し、遠位の自然角・解析torsion・材質係数は維持する。初期位置への追加復元は使わない。
3. nf3・FF/BF ONで現行/D/J/D+Jの2×2を一度設計し、単独と結合を識別する。初期幾何、共通short QC/replay、主比較、良好候補だけの摂動の順に進む。受入値は新結果を見る前にレビューする。

Dは有効回転体への出力トルク模型であり、原著Fig.2や実際の材料ねじれ輸送を忠実再現したとしない。拡散変数をねじれエネルギーの代用と呼ばない。完全なdirector rodへの書換えや元のtripletへの一括復帰は今回の第一案にしない。

## 変更しないもの

T/reference T=2.5e−20 N m、dt4 µs、粘性1 mPa s、FF反発ON、修正線分距離、解析torsion、材質係数、共通QC閾値。反発連続化・腕重み3方式・hookの単純硬化・Brownian追加を同時に導入しない。既存候補は履歴再現用で、既定profileをこのADRだけで変更しない。

## 検証・限界

[設計/根拠/採否案](../phase2/phase2_263_model_repair_direction.md)を正本とする。静的な長さ両立・clearance・保存則/仕事の成立は確認したが、Jの初期密束・動的安定性・束維持・摂動再現性は未確認。自然角配列を共通engine/QCが一致して読む実装が必要で、QC閾値緩和で代用しない。

本ADRは物理実装、cs10予約/開始、物理採択、merge、canonical freezeの完了を意味しない。実装と予約前検証は[runbook](../phase2/phase2_263_dj_runbook.md)を参照する。動的評価後に物理採択を判断する。
