# ADR 0026：torsion解析勾配とnf3束回転の診断候補

- Status: Proposed
- Source: Issue #255

## 背景

frame/motor修正後も束化は未達。#23でtorsion成分の総力・総トルク残差が増大した。保存15状態のFD刻み収束から、同じエネルギーの数値勾配の誤差が確認された。これを比較条件の共通の誤差源から外す。

## 判断

既定有限差分を維持し、同じwrapped quadratic torsion energyの解析勾配をopt-inで追加する。縮退とエネルギーcuspは明示失敗。全力/トルクを事後射影して見かけだけ保存させない。nf3のframe追加位置復元有無×motor横方向補正有無の4条件だけに選択する。

菌体側は実トルクへの局所全vector反作用を保つ。初期後方配置は回転軸の整列の初期条件であり、密な束を既に作った条件ではない。位置復元、横方向補正、排除体積の影響を混同しない。

毎内部stepで菌体相対のbest-fit axial spinを積算するopt-in outputと、共通QCを通ったarchiveの独立した再利用可能な束/回転診断を追加する。診断値を新しいQC gateやcanonical採択へ自動昇格しない。

## 帰結

既存profileと旧archiveの意味は維持。解析勾配を使う新結果と過去結果は物理ポテンシャルは同じでも数値実装が異なる。新4条件内の比較を優先する。nf4/5、hook剛性変更、#262の排除体積比較、2s拡張は含めない。候補の採択はユーザーレビュー後に別判断。
