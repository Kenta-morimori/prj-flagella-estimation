## 訂正：ビーズ距離proxyは実際の線分反発力ではない

`debug_summary._flag_flag_repulsion_metrics`の`flag_flag_repulsion_force_*`は、異なる鎖の**ビーズ**間距離に指数式を代入する参考値である。productionの`compute_segment_repulsion_forces`は**線分**間最近点を使う。したがって参考列が全step0でも、線分途中の反発力が0とは限らない。#42等について全内部stepの実力0とした旧推論を訂正した。元のsource/summaryは書き換えていない。

今回、全1002保存状態×4条件でproductionのactive pair選択・最近点・反発式を再評価し、菌体–鎖、異なる鎖間、同一鎖内非隣接を分離した。距離の全pair検算とAABB下界による厳密な除外は全4008状態の結果が一致。6時刻×4条件では反発合計normがproduction engineの再評価と一致した。

## 方針の確定と、次の具体的検証案

**今回は新たなM/K修正・再実行をしない。** 保存力・仕事・投影・source回帰・実行QCに、同仮説内のコード修正を正当化する不具合は見つかっていない。係数をさらに動かすことは根拠のある修理にならない。第1フェーズは2/5予約を使用して終え、未使用枠を消化しない。

次の優先順位は「実現可能な接続経路を作る静的設計」→「接続形状と菌体接触の因子比較」。候補名Gはこの未採択設計を指し、既存の密集同位相配置をそのまま採用する意味ではない。

1. **Gの静的成立性を先に確定する。** 当面はslots024とhook長.25µmを保ち、後方の近束軸へ滑らかにつながる近位経路を設計する。遠位らせん・自然長、全active pairのclearance、独立spin時のhook競合、残る初期応力、軸幅と相互角を同時に示す。剛体並進だけで成立しなければ、近位の離散化/有限hookの構成を変更候補として明示し、付着位置の変更は別案に分ける。未成立状態の動的計算はしない。
2. **成立したGに限り、次案はDJ driveを固定した2×2。** `J/BF ON`、`J/BF OFF`、`G/BF ON`、`G/BF OFF`。FFはON、T/dt/η/遠位材質を固定し、M/Kを同時採用しない。BF OFFは接触原因を問う診断対照で、採用候補はBF ON。Gの自然参照や離散化を変える場合は差分を独立した接続モデル変更として列挙し、「初期位置だけ」と呼ばない。
3. **判定を先に固定する。** 共通short QC/replay→1秒で、根元近傍の実segment接触/力、近位内部角、全体転向、遠位束幅/軸間角、材料spin/菌体自転/符号付き前進を同時刻で比較。ON/OFF差が大きければ接触経路を修正し、両方で開くなら接続の向き・曲げmoment伝達を優先する。Gも初期から広い、または束の入口を満たさなければ長時間延長しない。
4. **残仮説は混ぜない。** 近直線根元の曲げ構成則、有限hookのmoment伝達、cutoff不連続は未解決。新しい角度energyを採るなら客観性・保存力・完全moment釣合い・全rod負荷を示す別対照にする。cutoff連続化は後半接触の滑らかさを問う比較であり、Gやdrive修正へ同時に入れない。T/dt/粘性のsweep、body固定、追加位置復元力での固定は次案にしない。

このG/接続構造変更は今回の委任範囲外で、**設計提案まで・新予約無し**。モデル確定には近束成立後の複数周期・摂動・数値感度の確認も残る。現状を月内確定可能と断言できない。11/20判断点では、Gの静的成立と1秒での束形成を確認できなければ月内確定は高リスクと扱い、期限のために成功基準を下げない。
