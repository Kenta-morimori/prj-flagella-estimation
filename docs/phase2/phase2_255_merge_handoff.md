# Issue #255／PR #261：merge範囲と後続への引継ぎ

## 今回の範囲

初期hook配置、motor反作用、付着frameとtorsionの力計算を選択可能な実装として追加し、数値検証・実行結果・診断を保存する。既存profileの既定値、共通QC閾値、canonical model、dataset方針は変更しない。ADR 0023～0026は実装・候補の設計記録であり、Proposedな物理候補をmergeだけで採択済みへ変更しない。

時間発展中のhook対菌体軸90°偏差は診断専用。全ベクトル反作用によるmotor QCの成立と、望ましい遊泳挙動の成立を分ける。

## 確認できたことと限界

- 初期中立・菌体軸直交配置をhex13配置とproject n=1～3で確認し、1τで軸方向／全body全ベクトル／局所全ベクトル反作用を比較した。局所方式は16/16条件で共通QCを通過。
- hex局所方式の2s（queue #20）は13/13条件で完走・共通QC PASS。ただし束化・軸整列に懸念が残る。projectの2s（#21）は取消済みで未評価。hexの結果をprojectの長時間安定性へ一般化しない。
- frame・motor同時修正のnf3/4/5（#22/#23）では束遊泳の同時改善を確認できず、torsionの数値微分誤差を検出した。
- 同じtorsionエネルギーの解析勾配を使うnf3四方式（#24/#25）は共通QC 4/4 PASS。今回の初期配置・1sでは追加frame復元を外すと束の広がりが約26%縮小したが、密な定常束は未確認。
- C/Dは同位相でも束幅が変化しており、約2.5回転の観測から定常性を主張しない。対称配置での回転一致を自発同期と扱わない。

各実行の成果物は対応する結果文書に記載したローカルへ同期し、件数・SHA-256照合を記録済み。今回のmerge準備ではsimulation・再render・cs10操作を行わない。

## #263へ引き継ぐ基準

[Issue #263](https://github.com/Kenta-morimori/prj-flagella-estimation/issues/263)では、nf3四方式のC（`nf03__slots024__C`）を暫定基準にする。

| 項目 | 基準 |
|---|---|
| 菌体側motor反作用 | 実全ベクトルへの局所one-ring反作用、fallbackなし |
| frameの力計算 | energy_gradient。追加初期方向復元は無効 |
| torsion | 同じエネルギーの解析勾配 |
| motor横方向補正 | none。実トルクへの菌体反作用は維持 |
| 相互作用・物性 | まずCを継承。菌体–べん毛排除OFF、べん毛間反発ON |
| 診断 | 共通QC、力・トルク、菌体相対回転、束・周期診断を継承 |

初期束配置を設計し、束維持・軸整列・持続回転・推進を検証する。hook・motor構造変更は物理的根拠と対照を示して事前に設計する。基本は#263内で進め、膨大になった場合のみ子Issueへ分割する。自発的束形成、本数別特徴量評価、canonical採択は別判断。排除体積比較は#262との重複を避ける。

Cのみ2sの候補はユーザー判断で見送り。未予約・未開始で、承認待ちではない。未使用のcampaign・parallel-jobと期間一致だけの専用testはmerge準備で削除した。過去の予約や実行許可を新規実行へ流用しない。

- 最終候補へユーザー承認後にCloud reviewを一度依頼し、actionable threadを解消、codex-review-gateを通過する。
- 本PRをmergeしてもモデル採択・canonical変更は行わない。mergeそのものはユーザーの明示承認後に行う。
- PRは`Refs #255`を維持し、自動closeしない。merge後に当初目的の受入範囲・projectの未実施範囲・#263への引継ぎを照合して#255の完了を判断する。
